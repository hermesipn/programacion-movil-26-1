# Programación móvil 26-1

Este repositorio tiene el objetivo de compartir los códigos de los ejemplos que se realizan en clases y que les permitirán desarrollar sus tareas, prácticas y proyectos.

## Ejemplos

Los ejemplos que se desarrollen en clases se colocarán en el directorio _ejemplos_, y cuentan con las siguientes característricas:

- **Ejemplo 1:** Hola mundo

- **Ejemplo 2:** Tarjeta de felicitación

    La base de este proyecto la revisamos en clase, pero adicionalmente se agregó una imagen de fondo, además, las cadenas que estaban en _código duro_ se registraron como recursos, lo que mejora su mantenimiento y permite la implementación de la internacionalización.

- **Ejemplo 3:** Artículo

    Este proyecto tiene cómo objetivo agregar una imagen en el top de la pantalla, seguido de un par de párrafos.

- **Ejemplo 4:** Mensaje de confirmación con imágen

    Este tiene el objetivo de crear una interfaz que utilice todo el espacio disponible en el dispositivo; y en el centro muestre una imagen con un mensaje abajó de esta. La alineación de estos dos elementos debe ser centrada.

- **Ejemplo 5:** Pantalla en grid

    Este ejemplo busca que puedas segmentar el espacio disponible en la interfaz del dispositivo según los requerimientos que tengas que satisfacer; en este caso, segmenta la interfaz en una cuadricula.
